# Contribuindo

Obrigado por melhorar o Hacker Terminal.

## Ambiente local

Instale as dependências descritas no README e execute:

```bash
make check
make run
```

As mudanças devem continuar funcionando com GTK 3 e VTE 2.91. Evite adicionar comandos ofensivos ao painel; o escopo padrão é observabilidade local e defesa. Novas opções precisam ter um padrão seguro, aparecer em `--help` e ser documentadas.

## Pull requests

1. Mantenha a mudança focada e explique o comportamento antes/depois.
2. Inclua passos manuais para alterações visuais.
3. Rode `make check` e informe qualquer verificação que não pôde ser executada.
4. Não inclua fontes, binários ou dados de usuários no repositório.

Ao contribuir, você concorda que sua contribuição será distribuída sob a licença MIT do projeto.
