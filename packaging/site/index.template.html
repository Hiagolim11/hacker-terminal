Cada comando ganha uma marca na margem (vermelha quando dá errado) e o código de saída aparece na barra. Ctrl+Shift+↑ pula entre comandos; Ctrl+Shift+L copia só a saída do último.

Instale em um minuto.

Para sistemas Linux. O apt resolve as dependências sozinho.

1

Baixe o hacker-terminal___VERSION___all.deb na página de versões.

2

Instale com o apt:

sudo apt install ./hacker-terminal___VERSION___all.deb

Prefere sem pacote? Clone o repositório e rode ./install.sh, que instala só para a sua conta.

Perguntas frequentes

É grátis?

Sim. O Hacker Terminal é de código aberto, sob a licença MIT. O código está no GitHub.

Funciona com o meu shell?

Sim, ele abre o seu shell de sempre. A integração (marcas de comando, histórico, saltos) funciona com zsh e bash e é ligada sozinha; o resto vale para qualquer shell.

De onde vêm os sons de teclado?

São os pacotes oficiais do Mechvibes, gravados de teclados reais e distribuídos sob a licença MIT. Vêm compactados (2,5 MB no total) e você ainda pode importar outros pacotes.

Ele guarda minhas senhas?

Só se você pedir, e no chaveiro do sistema, nunca nos arquivos do terminal.

Onde ficam as minhas configurações?

Em ~/.config/hacker-terminal/: preferências, temas, perfis, ações e conexões. O histórico de comandos fica em ~/.local/state/hacker-terminal/, só no seu computador.

Como atualizo?

Baixe o novo .deb e instale com o mesmo comando do apt. Suas configurações continuam onde estão.
